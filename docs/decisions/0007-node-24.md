# 0007. Node 24 LTS

Status: accepted · 2026-09-11

**Context** — Node 22 is in maintenance and Node 24 is the active LTS. Staying on
22 was also holding back tools such as lint-staged 17, which needs Node ≥ 22.22.1.

**Decision** — Node 24.21.0, pinned in `.nvmrc` and `.node-version` (CI reads the
latter). `package.json` asks for `24.x` through `engines`, and with
`engine-strict` pnpm refuses to install on another major. The range stays at the
major on purpose: Dependabot runs pnpm on its own Node 24, and so may any host,
on a patch that can trail 24.21.0.

**Consequences** — every machine and CI run the same major. A patch update only
touches `.nvmrc` and `.node-version`; moving to the next LTS also changes
`engines` and deserves its own record.
